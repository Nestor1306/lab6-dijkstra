# Lab 6: Dijkstra's Shortest-Path Tree
Función `dijkstra_spt(initial, graph)` que usa el algoritmo de Dijkstra para
calcular el costo del camino más corto desde un vértice inicial a todos los
demás y el árbol de caminos más cortos. Materia: TC2008B.

Correr pruebas: `python -m unittest test_dijkstra_spt` (Python 3.12+).
